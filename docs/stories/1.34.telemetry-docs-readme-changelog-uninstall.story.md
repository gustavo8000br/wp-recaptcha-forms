# Story 1.34 — Documentação: READMEs, CHANGELOG, uninstall.php, nota de `readme.txt`

## Status
Draft

## Priority
P2 — não bloqueia código, mas **bloqueia release**: o README hoje contradiz a feature.

## Story
**Como** leitor do README e como auditor de changelog,
**quero** que a promessa "sem telemetria" seja reescrita para "telemetria opt-in, desligada de fábrica" com honestidade,
**para que** a documentação pare de ser a prova de que o projeto não cumpre o critério que ele mesmo estabelece.

## Backlog / Arquitetura
- `docs/telemetry-design.md` §5 (mudanças obrigatórias no README — redação proposta literal; `readme.txt` do WP.org; `CHANGELOG.md` com "telemetria" visível; `uninstall.php`), §0 (por que "sem telemetria" é compromisso de privacidade publicado, não detalhe), §7 (é MINOR)
- Decisão do dono T-5 (destino é o **WordPress.org** → a divulgação de "phoning home" tem que estar no `readme.txt`)
- `README.md` linha 46 e `README-EN.md` linha 45 (a frase atual, numa lista intitulada "o que ele **não** faz, dito na abertura para você não descobrir depois")
- Depende conceitualmente de 1.26–1.32 estarem definidas (a doc descreve o comportamento entregue); pode ser escrita por último

## Acceptance Criteria

1. `README.md` linha ~46: a frase **"Sem telemetria, sem relatórios, sem histórico de bloqueios."** é substituída pela redação de §5:
   > - **Sem telemetria ligada por padrão, sem relatórios, sem histórico de bloqueios.** Não há tabela nova no banco. Existe um envio opcional de estatísticas de uso, **desligado de fábrica**, que só passa a ocorrer se você marcar a caixa em Configurações → reCAPTCHA → Telemetria; a tela mostra o conteúdo exato antes de você decidir. Nenhuma atualização do plugin liga isso por você. O que existe sem telemetria são dois contadores em transient de uma hora, usados só para um aviso de diagnóstico, e que morrem sozinhos.
2. `README-EN.md` linha ~45: tradução equivalente da mesma frase ("No telemetry enabled by default, no reports, no history of blocked submissions. ... an optional usage-statistics send, off by default, ..."), coerente com o estilo do arquivo.
3. Se os READMEs tiverem uma seção sobre privacidade / "phoning home" mais abaixo, ela ganha um parágrafo curto apontando para a seção de telemetria da tela e para a política de privacidade da API. Sem redundância com o texto do `PrivacyNotice`.
4. `CHANGELOG.md` `[Unreleased]` → "Adicionado": entrada com a **palavra "telemetria" visível**, descrevendo: opção opt-in `telemetry` desligada de fábrica, envio semanal agregado, botão "ver exatamente o que será enviado", `WRF_TELEMETRY_DISABLE`, e classificando como **MINOR** (§7). Uma linha registrando que mudar o default para ligado seria MAJOR e que o projeto não pretende fazê-lo.
5. `uninstall.php`: confirmar (com comentário e teste — pode consolidar com a Story 1.27 AC 5) que a varredura por prefixo `wp_recaptcha_forms_` remove `wp_recaptcha_forms_settings` (carrega `telemetry.instance_id`) e `wp_recaptcha_forms_telemetry_counters`. Se algum artefato de telemetria ficar **fora** do prefixo (ex.: transiente de retry com nome próprio), ele entra explicitamente na lista de purga.
6. **Nota de `readme.txt`**: `readme.txt` no formato WP.org ainda não existe (issue #27 / pendência O-02, story própria da submissão). Esta story **não** cria o `readme.txt`, mas:
   - adiciona uma nota em `docs/wordpress-org-submission.md` (ou onde a submissão está sendo planejada) de que a seção de divulgação de telemetria — "phoning home", opt-in, desligado por padrão, link da política — **tem que entrar no `readme.txt`**, porque o revisor do WP.org lê esse arquivo, não o `README.md` (§5);
   - registra essa dependência no corpo da issue desta story e como checkbox pendente.
7. `docs/prd-v1.md` §6 continua listando telemetria como fora de escopo — **não editar aqui** (é a Story 1.35, território @pm). Esta story só referencia a 1.35 como pré-condição de coerência documental.
8. Teste/checagem: `grep -i "sem telemetria\b"` (a frase antiga exata, sem "ligada por padrão") não retorna nada em `README.md`; `grep -i "no telemetry\b"` idem em `README-EN.md` para a frase antiga; `grep -i telemetr CHANGELOG.md` retorna a entrada nova. Adicionar item ao `release-checklist.md`: "READMEs e CHANGELOG refletem a telemetria opt-in; `readme.txt` (quando existir) contém a divulgação".
