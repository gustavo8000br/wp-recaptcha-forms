# Story 1.9 — Integração com o plugin Newsletter (Stefano Lissa)

## Status
Draft

## Priority
P1 — Cobertura de formulários

## Story
**Como** operador que usa o plugin Newsletter,
**quero** proteger o formulário de inscrição com reCAPTCHA,
**para que** eu reduza inscrições automatizadas sem precisar de código customizado.

## Backlog / Arquitetura
- B-10, FR-10 (resolve D-09: só o form de inscrição, não cancelamento/perfil)

## Acceptance Criteria

1. `Newsletter\SubscribeIntegration` só é registrada se `defined('NEWSLETTER_VERSION')` — sem dependência dura, sem `Requires Plugins`.
2. Sem o plugin Newsletter instalado: zero erro, zero notice, a integração nem aparece no Registry (mesmo mecanismo de FR-13 para Woo).
3. Campo injetado no formulário de inscrição do Newsletter; validação antes do `subscribe` ser processado.
4. Recusa preserva os dados já preenchidos onde o hook do Newsletter permitir, com mensagem clara.
5. **Fora de escopo, confirmado:** formulários de cancelamento e perfil do Newsletter não são tocados por esta story.
6. Toggle próprio na tela de configurações.
7. Teste de integração com o plugin Newsletter real instalado no ambiente de teste, cobrindo: inscrição com token válido passa; inscrição bloqueada mostra mensagem; plugin desativado não gera erro.

## Tasks / Subtasks

- [ ] Hook de render + hook de validação do form de inscrição (AC 3, 4)
- [ ] Toggle no Registry (AC 6)
- [ ] Testes de integração com/sem o plugin instalado (AC 7)
