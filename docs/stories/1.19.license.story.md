# Story 1.19 — Licença GPLv2-or-later

## Status
Done

## Priority
P2 — Qualidade e distribuição (gate de release, bloqueia release público)

## Story
**Como** usuário que quer adotar o plugin,
**quero** uma licença clara e coerente com o header do plugin,
**para que** eu tenha segurança jurídica para instalar, modificar e redistribuir.

## Backlog / Arquitetura
- B-15, FR-15 (resolve D-02 — decisão do dono: GPLv2-or-later, arquitetura v1.1 §14)

## Acceptance Criteria

1. Arquivo `LICENSE` na raiz com o texto integral da GPLv2-or-later.
2. Header do plugin (`wp-recaptcha-forms.php`, Story 1.1) já declara `License: GPL-2.0-or-later` — esta story confirma coerência e adiciona `License URI` apontando para `https://www.gnu.org/licenses/old-licenses/gpl-2.0.html` ou equivalente oficial verificado.
3. `composer.json` declara a licença no campo `license`.
4. README (Stories 1.22/1.23) referencia a licença na seção apropriada — conteúdo mínimo aqui, detalhamento completo é das stories de README.
5. Decisão registrada como definitiva — sem reabertura futura (irreversível na prática após primeiro release público, conforme PRD §4.1).
