# Story 1.29 — Montagem do envelope `gm.telemetry/v1` e do payload `wp-recaptcha-forms/usage.snapshot/v1`

## Status
Draft

## Priority
P1 — é o dado em si. Reusada pela tela ("Ver exatamente o que será enviado", Story 1.32) e pelo transporte (Story 1.31).

## Story
**Como** autor do plugin,
**quero** um montador que produza o JSON exato do envio a partir do estado real da instalação, com proporções e baldes de volume,
**para que** o mesmo código gere o que a tela mostra e o que o cron envia, e para que nenhum campo proibido possa entrar.

## Backlog / Arquitetura
- `docs/telemetry-design.md` §1.1 (estrutura do envelope), §1.2 (campos um a um), §1.4 (o que o envelope nunca carrega)
- §3 (payload `usage.snapshot/v1` completo), §3.1 (por que cada bloco; `threshold_bucket` e não `threshold`; MINOR de PHP/WP), §3.2 (nunca, neste payload)
- Decisão do dono T-3 (**proporções + balde de volume, nunca contagens exatas**)
- Depende de 1.26 (opção `telemetry`, `seq`), 1.28 (`Counters::snapshot()`)

## Acceptance Criteria

1. `src/Telemetry/Envelope.php` (ou `SnapshotBuilder`) expõe `build(): array` devolvendo o envelope completo:
   ```
   schema = "gm.telemetry/v1"
   envelope_id = UUID v4 gerado agora (ver AC 7)
   sent_at = ISO-8601 UTC (gettimeofday no envio; na pré-visualização, agora)
   source = { project:"wp-recaptcha-forms", platform:"wordpress", version:WRF_VERSION, instance_id:Options::telemetry_instance_id() }
   environment = "production" | "staging" | "development" | "unknown"  (ver AC 6)
   event = { type:"usage.snapshot", occurred_at:ISO-8601 UTC, window:{from,to}, seq:<telemetry.seq + 1> }
   payload_schema = "wp-recaptcha-forms/usage.snapshot/v1"
   payload = { ...ver AC 3 }
   ```
2. `event.window.from` vem de `counters.window_from` (Story 1.28); `event.window.to` é o instante da montagem. Se `window_from` estiver vazio (nunca contou), `from` = `to` menos 7 dias e o payload marca volume `<100` / distribuição vazia — janela sempre declarada (§1.2).
3. `payload` segue **exatamente** a forma de §3:
   - **`plugin`**: `provider` (`v2`|`v3`), `threshold_bucket` (`<0.3`|`0.3-0.5`|`0.5-0.7`|`0.7-0.9`|`>0.9` — balde, nunca o float), `remoteip` (bool), `consent_mode` (`off`|`auto`|`required`), `policy_infra`, `policy_client_unreachable` (`allow`|`block`), `forms_enabled` (lista de `form_id` do **vocabulário fechado**, ordenada), `forms_enabled_count`, `kill_switch` (bool — `WRF_DISABLE` definido);
   - **`host`**: `php` (MINOR — `8.2`, nunca `8.2.11`), `wp` (MINOR), `mysql` (MINOR/MAJOR.MINOR, sem patch), `locale`, `multisite` (bool), `woocommerce` (versão MINOR ou ausente), `woocommerce_blocks_checkout` (bool);
   - **`verdicts`**: `total_bucket` (`<100`|`100-1k`|`1k-10k`|`10k-100k`|`>100k`), `distribution` (proporções somando ~1.0, 3 casas decimais, das 5 classes), `blocked_share`, `by_form` — **apenas formulários com ≥ 50 avaliações na janela** (§3.1), cada um com `share_of_total` e `client_unreachable` como proporções;
   - **`health`**: `misconfig_days_active` (dias desde `OPTION_MISCONFIG_SINCE`, 0 se limpo), `keypair_suspect_triggered` (bool de `OPTION_KEYPAIR_SUSPECT`).
4. **Contagens absolutas nunca aparecem no payload.** `verdicts` carrega só proporções e baldes. Teste que varre o payload serializado e falha se encontrar um inteiro > 100 fora de `forms_enabled_count`, `misconfig_days_active` e `event.seq`.
5. **Lista negra de campos proibidos** (§1.4 + §3.2), aplicada por um validador `Telemetry\PiiGuard::assertClean( array $envelope )` chamado ao fim de `build()`:
   - rejeita (lança `RuntimeException` sob `WP_DEBUG`, senão retorna envelope vazio + `last_status='pii_suspected'`) qualquer **chave** que case `/(^|_)(ip|email|url|domain|host|user|token|secret|key)($|_)/`;
   - rejeita qualquer **valor string** que case regex de e-mail, de IPv4/IPv6 ou de URL absoluta;
   - exceções nomeadas e explícitas para chaves legítimas que colidem com a regex (`site_key`/`secret_key` **não** existem no payload; `threshold_bucket` ok; `kill_switch` ok) — a exceção é uma allowlist curta, comentada.
6. `environment`: deriva de `wp_get_environment_type()` (`production`/`staging`/`development`/`local`→`development`); qualquer outro valor → `unknown`. Nunca obriga a mentir.
7. `envelope_id` é UUID v4 (`wp_generate_uuid4()`). Gerado por `build()`. O transporte (Story 1.31) **reusa o mesmo `envelope_id` no retry** — portanto `build()` aceita `?string $envelope_id = null` para o retry passar o anterior; a pré-visualização sempre gera um novo.
8. `src/Telemetry/` **não chama** `site_url()`, `home_url()`, `get_bloginfo()`, `get_option('siteurl')`/`'home'`, `$_SERVER['HTTP_HOST']`, `network_site_url()`. `locale` vem de `get_locale()` / `determine_locale()` (não é URL). Isso vira gate de CI na Story 1.30 — escrever já limpo.
9. Versão MINOR: helper `Telemetry\Version::minor( string $full ): string` → `"8.2.11"`→`"8.2"`, `"6.7"`→`"6.7"`, `"10.11.6-MariaDB"`→`"10.11"`. Testado nos casos de borda.
10. Testes:
    - envelope tem todas as chaves obrigatórias de §1.1 com os tipos de §1.2;
    - `threshold` 0.62 → `threshold_bucket` `"0.5-0.7"`, e o float **não** aparece em lugar nenhum;
    - `php`/`wp`/`mysql` sem componente de patch;
    - `by_form` omite formulário com 49 avaliações, inclui com 50;
    - `distribution` soma ~1.0 (tolerância 0.001);
    - `PiiGuard` rejeita um payload adulterado com chave `site_url` e outro com valor que é um e-mail;
    - `forms_enabled` só contém `form_id` do vocabulário fechado;
    - `seq` no envelope é `telemetry.seq + 1`;
    - `build( $id )` preserva o `envelope_id` passado.

## Dev Notes
- O montador é **puro**: recebe/lê estado, devolve array, não faz rede, não escreve opção, não incrementa `seq` (o incremento de `seq` e a gravação de `last_sent` são efeito do transporte pós-2xx, Story 1.31). Isso é o que permite a Story 1.32 chamar `build()` com o toggle desligado sem efeito colateral.
- `woocommerce_blocks_checkout`: reusar a detecção que a Story 1.11/1.13 já fez (Registry), não reimplementar.
- Limite de 64 KB do payload (§1.2): a estrutura é pequena por construção; um `assert` de tamanho em `Dev Agent Record` basta, não precisa de AC.
